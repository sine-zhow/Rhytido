## 1. 规格来源

| 类型 | 来源 | 说明 |
|---|---|---|
| 设计思想 | 优先级括号化打印（公有领域编译器技术） | 按运算符优先级决定是否加括号 |

## 2. 独立设计说明

- 递归渲染 interned AST；优先级表（加减 1 < 乘除 2 < 负 3 < 幂 4 < 原子/应用 5）。
- 右操作数对 `-`/`/` 的同优先级子树强制加括号（保结合语义）。
- M1 提供**规范十进制渲染**；Sollya 的 dyadic/binary/hex、midpoint、canonical、全括号等显示模式在表现精化阶段用参考语料逐一对齐（字节级）。
- 与任何参考表达无关：未参照 Sollya 打印器源码。
