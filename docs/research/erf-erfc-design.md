# erf / erfc 自研设计（M2-B，研究级）

> 2026-11-12 ｜ lead 主导。dashu 无 erf/erfc，需从公开数学定义独立实现（净室）。目标：任意精度、严格误差界、faithful/正确舍入证书。

## 1. 定义与性质（公有领域数学）

- `erf(x) = (2/√π) ∫₀ˣ e^{-t²} dt`；`erfc(x) = 1 − erf(x) = (2/√π) ∫ₓ^∞ e^{-t²} dt`。
- 性质（测试锚点）：erf 奇函数；erf(0)=0、erf(±∞)=±1；erfc(0)=1、erfc(+∞)=0、erfc(−∞)=2；erf+erfc=1；erf 单调增。
- 关键上界（x>0，严格）：`erfc(x) ≤ e^{-x²}/(x√π)`。证明：t≥x ⇒ 1≤t/x，故 ∫ₓ^∞ e^{-t²}dt ≤ ∫ₓ^∞ (t/x)e^{-t²}dt = e^{-x²}/(2x)。

## 2. 算法：统一幂级数 + 大参数截断（ avoids 连分式界）

**小/中参数幂级数**（对所有 x 收敛）：
`erf(x) = (2/√π) Σ_{n≥0} (−1)ⁿ x^{2n+1}/(n!(2n+1))`。
项递推：`a_0=x`，`a_{n+1} = a_n · (−x²)(2n+1)/((n+1)(2n+3))`。

**严格余项界**：项比 `|a_{n+1}/a_n| = x²(2n+1)/((n+1)(2n+3)) ≤ x²/(n+1)`。当 `n+1 > x²` 项单调降；截断到 N（N+2>x²）后
`|R_N| ≤ |a_{N+1}|/(1−r)`，`r = x²/(N+2) < 1`（几何级数控制）。取 N 使 `|a_{N+1}|/(1−r) < 2^{−P}`。

**大参数提前返回**：若 `e^{-x²}/(x√π) < 2^{−p−guard}`（用 §1 上界判定），则 erfc(x) 在目标精度 p 下舍入为 0、erf(x)=±1。充分条件 `x² > (p+guard)·ln2 + ln(x√π)`；保守用 `x² > p+guard`（因 ln2<1）。阈值约 `x > √p`。

## 3. 相消精度分析（关键，决定工作精度 P）

级数量级和 `Σ|a_n| ~ e^{x²}`（≈2^{1.443x²} 位）。在精度 P 下逐项舍入，erf 的绝对误差
`ε_erf ≈ 2^{−P}·Σ|a_n| ≈ 2^{−P+1.443x²}`（再加可忽略的截断余项）。
- erf 本身（值~1）：相对误差 ≈ ε_erf，需 <2^{−p} ⇒ `P > p + 1.443x²`。
- erfc=1−erf（值~2^{−1.443x²}）：绝对误差仍 ε_erf，相对误差 ≈ ε_erf/erfc ≈ 2^{−P+2.886x²}，需 <2^{−p} ⇒ `P > p + 2.886x²`。

**取 `P = p + 3·ceil(x²) + guard`**（guard≈10–20）同时覆盖 erf 与 erfc。阈值处 x²≈p ⇒ P≈4p，项数 ~O(x²)，任意精度下可行。**先正确后快**：统一 1−erf 路径，避免连分式截断界的复杂性；后续可优化大参数 erfc 直接级数。

## 4. 舍入与证书（Ziv 式）

1. 计算 `S=Σa_n`（精度 P，带 §2 余项界）、`√π`（精度 P）、`erf_P=(2/√π)·S`、`erfc_P=1−erf_P`。
2. 总误差界 E = 截断界 + 舍入累积界（§3）。若 `E < 0.5·ulp_p` ⇒ 正确舍入；`E < 1·ulp_p` ⇒ faithful；否则提升 guard/P 重试（Ziv）。
3. 依区间/误差界落点定 8 态证书（Exact/CorrectlyRounded*/Faithful*），随 FpResult 返回；大参数提前返回给 Exact（erf=±1、erfc=0 为精确极限值，按 Sollya 语义标注）。
4. 特殊值：NaN→NaN；±∞ 按 §1；erfc(−∞)=2。

## 5. 测试策略（三层，AGENTS.md §4）

- **模块层**（tests/bigfloat.rs 追加或 tests/erf.rs）：
  - 正常：erf(0)=0、erfc(0)=1、erf(1)/erfc(1) 等与**公开高精度参考值**交叉核对（如 erf(1)=0.84270079294971486934122063508260925929606699796630…，取 ≥50 位断言）。
  - 极端：±∞、大参数（erfc→0）、小参数（erf≈2x/√π）、阈值邻域。
  - 异常报错：NaN 传播。
  - 异常中断：全特殊值组合不 panic。
- **属性/集成**：erf+erfc=1（高精度）、奇对称 erf(−x)=−erf(x)、单调性（采样）、erfc=1−erf 一致性、与数值积分/已知导数 `erf'(x)=2e^{-x²}/√π` 交叉核对（M2-D autodiff 后）。
- **单元层**：级数递推、余项界、阈值判定等私有辅助的内联测试。

## 6. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 相消导致精度不足 | §3 显式 P=p+3ceil(x²)+guard；属性测试 erf+erfc=1 在高精度下验证 |
| 余项界误用（项未单调降） | 强制 N+2>x² 才用几何界；单元测试覆盖 |
| 大参数阈值误判 | 用严格上界 erfc≤e^{-x²}/(x√π)，保守阈值；阈值邻域测试 |
| 参考值来源 | 用公开数学常数/文献值（净室），不复制 Sollya 代码 |
