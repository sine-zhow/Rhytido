## 1. 项目定位

Rhytido 是用 **Rust 净室重实现** Sollya 的数值软件：一个"安全浮点代码开发"引擎，提供任意精度求值（带舍入质量证书）、认证多项式逼近、认证范数、以及面向 libm 的 C 代码与 Gappa 证明生成。**完全不复制 Sollya 源码**，仅以公开文档、数学论文与行为测试为规格来源。

## 4. 执行摘要

- **架构**：8 层无环依赖（数值后端 → 核心值/表达式 → 求值引擎 → 逼近与认证 → 语言 → 代码生成 → 表现/IO → 接口）。**语义引擎与表现层分离**，从而同时支撑语义级与字节级兼容。**数值后端 facade** 是唯一接触具体大数库的层，保证低耦合与可切换。
- **内存安全**：核心全 safe Rust；`unsafe` 仅存在于 FFI 边界（后端 sys 调用、C ABI）并被封装审计；以**所有权 + arena/interning** 取代 Sollya 的手工引用计数与全局回收链表。
- **性能**：scratch/workspace 复用、表达式 interning 结构共享、热路径免分配、基准驱动优化。
- **兼容**：语义级保证结果与语义一致（动态作用域、error 一等值、符号回退、质量证书、认证界）；字节级在其上复刻 Sollya 的打印器与 487 条消息目录，直接复用现成测试语料做 `diff` 回归。
- **绑定**：C ABI（cdylib + 符号版本脚本 + 边界捕获 panic）→ C/C++ 头封装 → Python（ctypes/cffi 或 PyO3）。
- **路线**：M0 数值地基 → M1 表达式+打印器 → M2 求值引擎 → M3 语言+CLI → M4 多项式+Remez+范数 → M5 认证+forms+fpminimax → M6 代码生成+外围 → M7 绑定+全量测试 → M8 研究增强。每里程碑有独立验收。

## 6. 顶层风险（详见 03 文档风险登记册）

1. **净室可辩护性**：我们已深度精读源码，"净室"主张需以"从公开规格/测试实现、不复制表达、留存溯源记录 + 法务审查"来加固。
2. **字节级输出保真**：定制 printf（约 1500 行）+ 487 消息 + `mpfr_get_str` 数字生成；倾向 rug 后端复现同一 MPFR。
3. **后端许可证**：rug/malachite/fplll 为 LGPL；以动态链接 + facade 隔离合规，或选 dashu 全宽松路线。
4. **性能对标**：Sollya 的回收池/scratch 复用优化极重，需基准驱动而非朴素实现。
5. **范围蔓延**：全量 parity 是大工程；以里程碑分级、核心先行控制。
